# Review keys

In Library's Works view, single keys review the open work one field at a time.
A key presses the control it names on screen, so it records exactly what that
control records.

| Key | Action |
|---|---|
| J | Opens the next field. After the last field it opens the next work in the list. On Review complete it presses Review next work. |
| K | Opens the previous field. Before the first field it opens the previous work. On Review complete it reopens the last field. |
| 1, 2, 3 | Chooses the value with that number. Values are numbered in the order shown, Keep current value first. |
| E | Opens Enter a value, Change or Choose genres. |
| U | Withdraws your decision on the open field, as Withdraw does. |
| ? | Lists these keys. |

J and K step through the fields shown and skip those behind `Show N more
fields`. They stop at the first and last work on the page. A value or control
that is not wholly on screen is brought into view first, and the next press
uses it.

Keys act while focus is in Library, not in the masthead. They do nothing while
you type, while a form or Attention is open, while a choice is recording, or
with Ctrl, Alt or Command held. A key whose control is not offered does
nothing.

Keys in the Library toolbar lists them and turns them off or on in this
browser. While they are off, no key acts, ? included. A phone or tablet shows
neither the numbers nor Keys, and the keys still work with a keyboard attached.
