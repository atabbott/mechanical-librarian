# ADR-0049: Activate owner-confirmed cover considerations

Status: Accepted

## Context

ADRs 0045–0047 established exact report-bound cover packets, conservative
identity admission, contained policy-neutral observations, and deterministic
policy advice in the contributor workbench. The retained engineering benchmark
shows this machinery is useful for owner assistance, while also showing that
composition labels are judgements rather than objective ground truth. The
installed product already owns immutable human decisions and a guarded,
verified Audiobookshelf cover effect path.

## Decision

Promote the existing packet, identity, observer, and policy modules into the
installed application without creating a second review or write system. One
exact-current cover field produces an immutable consideration containing the
incumbent first and at most 12 safe report-bound alternatives. It binds the
source report, original and canonical transport artifacts, packet, identity
classifier, observer profile/model/instruction/taxonomy/output schema, and
deterministic policy. Material input or contract changes create a successor;
identical replay reopens the same record and an explicit retry creates a new
attempt record.

The observer and policy are advisory only. The owner explicitly keeps the
incumbent, selects one displayed identity-admitted non-incumbent original, or
takes no action. Observation failure retains a fully supported model-free
manual path. Decisions and consideration/supersession/outcome events are
append-only. A selected original enters the existing human-decision and guarded
field-effect machinery; immediately before application that path revalidates
the current case, consideration, process policy, target fingerprint, incumbent
cover digest, selected original digest, consent, capability, backup readiness,
and ordinary verification/reconciliation gates.

Authenticated image transport exposes only the bounded application-owned PNG
preview for the exact current consideration. It is private/no-store and is not
an original-download, provider, arbitrary-path, or generic image endpoint.
Automatic model-selected writes, bulk reevaluation, silent learning, new
providers, media writes, and production-library qualification remain excluded.

## Consequences

The browser and installed CLI share the same server-authoritative
consideration, choice, and history meanings. A contained reviewer can improve
advice but can neither admit identity nor decide or write. Missing configuration,
observer failure, or absent recommendation degrades to manual comparison; it
does not reinterpret a technical failure as semantic incapability.

The clean pre-release schema gains immutable consideration and event tables plus
one mutable exact-current pointer. Existing field-effect audit history remains
the application history. This supersedes only the source-only/runtime-excluded
provisions of ADRs 0045–0047; their evidence, containment, identity, policy, and
benchmark limits remain binding.

## Validation

- Unit and architecture tests cover exact bindings, replay/successor behavior,
  unavailable/failed observation, closed owner choices, immutable persistence,
  authenticated image transport, and policy-current guarded application.
- The exact installed container must pass fake-service cover application and
  direct browser inspection without production credentials or writes.
- The versioned 0.15.0 engineering benchmark is replayed aggregate-safely with
  retained artifacts. It is not a medical trial, objective aesthetic truth, or
  unseen-generalisation claim.
